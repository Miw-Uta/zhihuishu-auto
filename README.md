# 智慧树自动刷课 (zhihuishu-auto)

一款轻量、纯净的 **Chrome / Edge 浏览器扩展（Manifest V3）**，同时兼容智慧树（知到）**新版**与**旧版**课程学习页：

- **新版**：`wisdom-mooc.zhihuishu.com/study/index`（Vue 3 + Element Plus 全新页面）
- **旧版**：`studyvideoh5.zhihuishu.com/stuStudy`（Vue 2 + Element UI 经典页面）

所有逻辑均在本地浏览器运行，不联网、不收集任何个人数据，仅使用 `chrome.storage.local` 保存开关配置与本地统计。

---

## ✨ 功能特性（新版页面）

- **自动播放与静音**：进入课程页后自动静音播放；缓冲、意外暂停自动恢复；播放卡住 12 秒自动重试。
- **弹题自动作答**：自动识别题型（单选/多选/判断）与题干选项，通过页面组件的事件处理函数直接作答（零合成事件，不受 `isTrusted` 校验拦截）。答题策略可选：
  - **语义/首项作答**（推荐）：判断题按题干语义启发式选择，单选/多选选首项提交；
  - **随机作答**：随机选项提交。
  - 弹窗答完自动关闭，通知弹窗自动确认，视频自动续播。
- **完成状态三态判定**：已完成（完成图标）/ 进行中（进度百分比）/ 未开始——视频播完未拿到完成图标时不会误判。
- **自动切换下一节**：当前小节拿到完成图标后自动切换（含跨章节，自动展开折叠面板）；跳过「测试」条目；打开页面自动跳到第一个未完成小节。
- **播完未结算自动重播**：视频播完但平台未结算完成图标时（进度未满），自动从 00:00 重播当前小节直至结算，避免"播完了但不算完成"。
- **切后台 / 最小化继续播**：维持后台心跳，后台标签页按真实时间驱动学习计时。
- **面板状态展示**：实时显示播放进度、当前小节、完成计数、弹题处理状态、最近日志。

### 旧版页面（保持原有能力）

- 弹题自动满分作答（读取页面数据中的标准答案标记 `result === 1`，支持单选/多选/判断/多题连弹）。
- 未满进度自动重播补刷；自动过网易易盾 3D 点选安全验证（需配置 AI 视觉模型 API Key）。
- 详见仓库历史版本说明。

> ⚠️ **新旧版自动作答机制差异**：旧版将正确答案标记随题目下发到前端，插件可读取后满分作答；**新版答案不下发前端**（提交后才公示），且答错即定稿无法重答——因此新版单选/多选的首答正确率受此限制（判断题有语义启发式可部分命中）。

## 📦 安装方法

> **环境要求**：Chrome 111+ 或 Edge 111+（依赖 Manifest V3 的 `world: "MAIN"` 内容脚本支持）。

### Edge 浏览器

1. 地址栏输入 `edge://extensions` 并回车。
2. 打开「**开发人员模式**」。
3. 点击「**加载解压缩的扩展**」，选择本项目文件夹。
4. 将扩展图标固定到工具栏。

### Chrome 浏览器

1. 地址栏输入 `chrome://extensions` 并回车。
2. 打开右上角「**开发者模式**」。
3. 点击「**加载已解压的扩展程序**」，选择本项目文件夹。

## 🚀 使用说明

1. 登录智慧树，进入课程学习页（新版 `wisdom-mooc.zhihuishu.com/study/index?recruitAndCourseId=...` 或旧版 `studyvideoh5.zhihuishu.com/stuStudy?recruitAndCourseId=...`）。
2. 插件自动识别页面版本并接管播放器；点击工具栏图标可查看实时状态。
3. 弹题出现时插件自动作答并关闭弹窗（策略可在面板切换）；视频播完自动切换下一节。
4. **注意**：扩展重新加载后必须刷新课程页面，否则旧脚本上下文失效。

### 面板配置项

| 选项 | 默认值 | 说明 |
| :--- | :---: | :--- |
| **总开关** | 开启 | 关闭后插件暂停一切自动操作 |
| **自动静音** | 开启 | 自动静音播放，确保浏览器允许自动播放 |
| **播完自动下一节** | 开启 | 当前小节结算完成（出现完成图标）后自动切换 |
| **跳过已完成章节** | 开启 | 跳过带完成图标的已学小节与「测试」条目 |
| **切后台/最小化继续播** | 开启 | 后台心跳维持学习计时 |
| **自动答弹题** | 开启 | 检测到随堂练习弹窗自动作答 |
| **答题策略（旧版）** | 自动选正解 | 读取页面数据标准答案满分作答 |
| **新版答题策略** | 语义/首项作答 | 「语义/首项作答」或「随机答题」 |
| **自动过安全验证（AI 视觉，旧版）** | 开启 | 旧版网易易盾 3D 点选验证码自动识别 |

> **安全验证说明**：新版页面的腾讯滑块验证码出现时需要人工完成，插件不会尝试绕过任何验证码或身份校验。

## 🛠️ 技术架构

```text
zhihuishu-auto/
├─ manifest.json          # MV3 清单（双域名 content_scripts）
├─ debug-scan.js          # 开发诊断工具：Vue vnode 组件树扫描（可选，不影响扩展运行）
└─ src/
   ├─ background.js       # Service Worker：配置初始化、图标角标、心跳、AI 验证服务
   ├─ page-detect.js      # 页面版本识别 + SPA 路由监听（双版本共用）
   ├─ config.js           # 旧版选择器配置
   ├─ app.js              # 旧版适配主体（环境门控：仅旧版域名启动）
   ├─ main-world.js       # MAIN world：旧版防检测补丁 + 新版 vnode 事件桥（quizSelect/Submit/Close/noticeConfirm）
   ├─ modern-config.js    # 新版选择器配置（全部来自实测页面，标注来源）
   ├─ modern-adapter.js   # 新版适配主体：播放控制、目录三态、切集、弹题状态机、自动作答
   └─ popup.html/js/css   # 扩展面板：开关、策略、实时状态
```

### 新版适配的关键技术

1. **vnode 事件桥**：新版弹窗的交互由 Vue 3 vnode 的 `props.onClick` 驱动。插件在 MAIN world 遍历组件树（从挂载容器的 `_vnode` 入口，穿透 Teleport/Fragment/slots），找到目标元素的点击处理函数**直接调用**——与页面真实点击走完全相同的代码路径，无需合成事件。
2. **弹窗常驻 DOM 的可见性判定**：Element Plus 弹窗组件预挂载常驻，关闭后 DOM 仍在——所有"弹窗是否存在"的判定均做 `getBoundingClientRect` 可见性检查，避免误报与空点。
3. **完成状态三态**：`.item-box` 内 `img.finish-icon`（已完成）→ `.el-progress[aria-valuenow]`（进行中）→ 皆无（未开始）；视频 `ended` 事件只作观察触发，**不作为完成依据**。
4. **切集防重复**：切换锁 + 同目标去重 + `.current` 标记转移验证三重保险。
5. **环境门控**：旧版逻辑只允许在旧版域名运行，新版页面由独立适配模块接管，互不干扰。

## 🔍 调试与排错

在课程学习页按 `F12` 打开开发者工具（Console，上下文选 `top`）：

- 过滤 `[ZHS]`（旧版）、`[ZHS-M]`（新版适配器）、`[ZHS-MW]`（MAIN world）、`[ZhihuishuAuto]`（页面识别）可查看各层日志。
- 新版页面在 Console 输入以下命令可读取实时状态快照：

```js
JSON.parse(document.documentElement.getAttribute('data-zhs-modern'))
```

- 旧版页面输入 `__ZHS_STATUS__()` 查看状态。
- 平台改版导致选择器变化时，优先修改 [src/modern-config.js](src/modern-config.js)（新版）或 [src/config.js](src/config.js)（旧版），随后在扩展管理页刷新生效。
